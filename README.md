# Telecommunications_Customers_Churn_Analysis

## Tools Used
- Microsoft Excel
- Mysql
- Power Bi

## Project Overview
This project includes data cleaning and preparation process for the Telco Customer Churn Analysis project using Excel Power Query to clean and prepare the dataset for SQL analysis and Power BI visualization.

## What I Learned
- How to clean messy data using power query in Microsoft Excel.
- How to import datasets and write proper queries in MYSql
- How to use Power Bi for Insights visualization.
